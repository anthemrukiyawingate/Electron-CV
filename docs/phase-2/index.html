LEARN BY BREAKING THINGS
01 /

The bridge is not a sanitizer

Context isolation separates JavaScript worlds. It does not make untrusted data safe by itself.

02 /

Validate at the authority boundary

Main must check the sender, operation, types, and exact schema before performing privileged work.

03 /

Return data, never execution

The accepted operation returns a small status object. No arbitrary paths, channels, or source code pass through.
